# Agents Anywhere 2.1.0

2.1.0 是接口更新（MINOR）：Server 新增语音识别端点，所有端版本号统一升到 2.1.0。本记录只描述源码变化，尚未构建、上传任何安装包。

## 接口变化

- 新增 `GET /api/v2/speech/status` 与 `POST /api/v2/speech/transcriptions`，详见 [Speech API](../api/speech.md)。
- Server 新增可选配置 `AGENT_SERVER_ASR_URL`，指向自部署的语音识别服务。未配置或服务不可用时，status 返回 `available: false`，转写接口返回 503 `speech_unavailable`。
- 语音识别不属于有效能力（capabilities），实时事件、Runtime 协议和 `contracts/` 均无变化。

## 产品变化

- Android 语音通话模式：在会话中点电话按钮进入免提对话，锁屏也能口述指令、听 Agent 回复，支持「停止 / 同意 / 拒绝 / 重复 / 挂断」口令。识别可以选手机自带的服务，也可以选服务器上的 SenseVoice-Small。
- 新增 `docker/asr` 语音识别服务（sherpa-onnx + SenseVoice-Small int8，纯 CPU），`docker-compose.postgres.yml` 默认包含该服务并为 Server 配置好地址。

## 最低配套版本

| 功能 | 要求 |
| --- | --- |
| 语音通话（手机识别） | Android ≥ 2.1.0，任意 2.x Server |
| 语音通话（服务器识别） | Android ≥ 2.1.0，Server ≥ 2.1.0，并部署 `docker/asr` |

旧客户端不调用新端点，不受影响；Android 2.1.0 连接旧 Server 时 status 请求失败，界面只提供手机识别。

## 部署

- Compose 部署：`docker compose -f docker/docker-compose.postgres.yml up -d --build` 会同时构建 `asr-next`。构建时从 `k2-fsa/sherpa-onnx` 的 `asr-models` release 下载模型包（约 1 GB，镜像内只保留约 230 MB 的 int8 模型）。镜像约 750 MB，运行时内存约 350 MB。
- 其它部署方式：单独运行 `docker/asr` 镜像，并给 Server 设置 `AGENT_SERVER_ASR_URL`。ASR 服务没有鉴权，不要暴露端口。
- 不部署 ASR 也可以升级到 2.1.0，只是没有服务器识别。

数据库 schema 无变化，不需要迁移。

## 已知验证

- Server：`tests/test_speech_api.py` 19 项通过；Windows 本机全量测试的失败与本次改动无关（符号链接权限、缺少 tzdata、CRLF、Windows 计时精度与文件权限）。
- ASR 镜像：本机构建成功；用合成的 7.4 秒中文语音经 Server 接口转写，结果与原文一致，解码约 0.35 秒。
- Android：单元测试与 `assembleDebug` 通过。真机试用中发现服务器模式的录音端点检测没有切出语音（Server 日志里没有任何 `/speech/transcriptions` 请求），已改为相对噪声底和本句峰值的判定，并在界面显示录音进度、在 logcat `AAVoice` 标签记录每句的音量与上传结果；修复后尚未在真机复测。播报（TTS）在一台真机上没有声音，原因未查明。
- iOS、Web、Desktop、Connector、DSH 插件只改了版本号，未做功能验证。
